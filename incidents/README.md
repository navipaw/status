# Incidents

Notices published to the status page.

**To post one:** Actions → *Post incident update* → Run workflow. Reuse a slug to
add an update to an existing notice; a new slug starts a new one. Or copy
`TEMPLATE.md` to `YYYY-MM-DD-slug.md` and commit it.

Nothing closes automatically. Post a `resolved` update to close.

**This is public.** Write for a customer who cannot use the product: what they
cannot do, what still works, when you will update next. Never include internal
detail, error output, hostnames, addresses, account information, or credentials.
